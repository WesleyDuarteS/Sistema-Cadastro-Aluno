# Sistema de Cadastro de Alunos

Aplicação desenvolvida em Java e executada no terminal para cadastrar diferentes tipos de alunos, consultar mensalidades e calcular o valor total arrecadado.

## Funcionalidades

* Cadastro de alunos regulares, bolsistas e integrais
* Consulta de dados pessoais dos alunos
* Consulta do valor da mensalidade
* Aplicação de desconto para alunos bolsistas
* Cálculo do valor total arrecadado com mensalidades
* Menu interativo executado no terminal

## Conceitos aplicados

* Programação orientada a objetos
* Herança
* Polimorfismo
* Encapsulamento
* Sobrescrita de métodos
* Listas de objetos

## Tecnologias

* Java
* IntelliJ IDEA
* Git
* GitHub

## Como executar

Clone o repositório:

```bash
git clone https://github.com/WesleyDuarteS/Sistema-Cadastro-Aluno.git
```

Abra o projeto no IntelliJ IDEA e execute a classe que contém o método `main`.
